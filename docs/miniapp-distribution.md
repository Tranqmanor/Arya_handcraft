# 小程序体验版分发指引

> 适用场景:将 Arya手作 小程序以**体验版**形式分发给特定人群使用(无需微信认证、无需提交审核)。
> 正式全量发布的路线图见文末附录。

## 一、分发前置检查清单

- [ ] 后端服务健康:`https://aryahandcraft-production.up.railway.app/api/v1/health` 返回 `"status": "ok"`
- [ ] `mini-program/.env.production` 中 `VITE_API_BASE` 为上述生产 API 地址
- [ ] `mini-program/src/manifest.json` 中 `mp-weixin.appid` 为已注册的小程序 AppID
- [ ] 你拥有该小程序的**开发者/管理员**身份(登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) 可见"版本管理")

## 二、构建与上传

```bash
cd mini-program
npm run build:mp-weixin     # 产物输出到 dist/build/mp-weixin
```

1. 打开**微信开发者工具** → 导入项目 → 目录选择 `dist/build/mp-weixin`,AppID 填小程序真实 AppID;
2. 工具内编译预览,确认首页轮播/视频/文章/Arya 四个 Tab 数据正常;
3. 点击右上角 **上传**,填写版本号(如 `0.1.0`)与备注(如 `首轮体验版`)。

## 三、设为体验版并添加体验成员

1. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) → **管理 → 版本管理** → "开发版本"中找到刚上传的版本 → 点 **选为体验版**,生成体验版二维码;
2. **管理 → 成员管理 → 体验成员** → 添加成员微信号(上限约 100 人);
3. 将体验版二维码发给体验成员,扫码即用。

## 四、⚠️ 体验成员必读:首次打开需开"开发调试"

由于当前后端域名 `*.railway.app` 为境外域名,**无法配置进小程序 request 合法域名白名单**(白名单要求 HTTPS + ICP 备案),因此体验版在手机上默认会被拦截网络请求。请每位体验成员:

1. 打开小程序后点右上角 **⋯(胶囊菜单)**;
2. 选择 **开发调试** → 打开(会弹提示并自动重启小程序);
3. 重启后即可正常浏览与对话;顶部会出现黄色"调试中"提示条,属正常现象,不影响功能。

> 不开调试的表现:首页轮播/各列表空白,Arya 页发送消息无响应(vConsole 中可见 `url not in domain list` 报错)。

## 五、常见问题排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 各页面数据空白 | 未开启"开发调试" | 按第四节操作 |
| 仅部分图片不显示 | 图片源(R2)防盗链或失效 | 到管理后台核对图片 URL |
| 所有请求失败且 vConsole 显示 CORS/域名校验错误 | 同"数据空白" | 开发调试开关 |
| Arya 回复报错 | LLM 服务异常 | 查 Railway 日志与 `/api/v1/health` diagnostics |
| 提示"该小程序未发布" | 正常,体验版本就未发布 | 忽略 |

## 六、附录:正式发布路线图(免认证上架)

个人主体小程序**可以不经认证直接提交审核上架**,但需依次解决:

1. **域名备案(必须)**:购买国内域名 → 完成 ICP 备案(需一台最低配国内云服务器作接入)→ 反代/CNAME 至 Railway 服务 → 将新域名填入公众平台"服务器域名"与 `mini-program/.env.production`;
2. **AIGC 类目风险(高)**:"Arya智能小助手"提供 LLM 对话,审核可能要求深度合成/生成式 AI 相关资质,个人主体难以满足;若被拒,可评估调整 AI 入口形态,或升级个体工商户主体;
3. **类目选择**:个人主体可选类目有限,建议按"生活服务/手工制品展示"方向申报;
4. 个人主体固有限制:无微信支付、部分接口不可用。
