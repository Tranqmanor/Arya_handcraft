# Arya_handcraft · 设计规范

> 对应 preplan.md 2.7 / 8.5;莫兰迪色系 + 可爱萌宠风(非具象宠物图标)。版本 v1.0(2026-08-18)

## 1. 设计关键词

软萌 · 温暖 · 手作感 · 低饱和 · 圆润

## 2. 色板(莫兰迪)

| 用途 | 色名 | HEX | 说明 |
|---|---|---|---|
| 主色 | Morandi Pink | `#C9A9A6` | 按钮/强调/选中态 |
| 主色深 | Clay | `#A98B84` | 主色 hover/文字强调 |
| 点缀蓝 | Mist Blue | `#9FB0B5` | 小面积点缀(标签/角标) |
| 点缀绿 | Sage | `#A8B3A0` | 小面积点缀(成功/新客券) |
| 点缀黄 | Warm Sand | `#D9C7A5` | 小面积点缀(提醒) |
| 背景 | Cream | `#FAF6F0` | 页面底色 |
| 卡片 | Porcelain | `#FFFFFF` | 卡片/弹窗 |
| 正文 | Ink | `#5A5350` | 主文字 |
| 辅助 | Dove | `#B9B1AC` | 次要文字/占位 |

规则:大面积用 Cream/白;主色只用于关键操作与选中态;蓝绿黄点缀比例 ≤10%;不使用高饱和/荧光色。

## 3. 字体与圆角

- 字号:12 / 14 / 16 / 18 / 22(sp);标题 22sp 加粗,正文 14sp。
- 圆角:卡片 16rpx/12px,按钮 999(胶囊),弹窗 24rpx。
- 阴影:柔和低透明度(如 `0 4px 12px rgba(90,83,80,0.08)`)。

## 4. 图标与插画

- 图标:线性圆角描边(2px),默认 Dove/Ink 色,选中态主色;可含猫爪/毛线球/爱心/云朵等**抽象简化图形**,避免写实宠物。
- 欢迎页:品牌字 + 抽象猫爪/毛球插画 + 渐变 Cream→Pink 背景,2 秒淡出进入主界面。
- Tab 图标:四个(video/article/arya/mine),统一 40rpx。

## 5. 通用组件约定

| 组件 | 规范 |
|---|---|
| 按钮 | 胶囊形,主按钮 Pink,次按钮 白底 Ink 描边 |
| 卡片 | Porcelain 底、16rpx 圆角、轻阴影 |
| 空状态 | 灰猫爪插画 + Dove 文案 |
| 加载 | 骨架屏(Porcelain 骨架,非转圈) |
| 标签 | Mist Blue 底标签(如「教程」「定制」) |
| 弹窗(二维码) | 白底圆角,二维码 480rpx,下附「长按识别」提示 |

## 6. 落地方式

- uni-app/后台:把色板写入主题变量(`styles/theme.scss` / CSS 变量),全局引用,禁止散落写死颜色。
- 图标:使用 Icon 组件或 SVG;不引入真实宠物照片作图标。
